# 分类与标签体系 · Taxonomy

## 设计原则：投稿者零决策

**目录只按「来源」分层**，投稿者第一眼就知道放哪；「杖的类型」不进目录，作为元数据标签（`index.csv` 的 `category` 列）在表单里勾选，选错不改变存放位置，维护者合入时校准。

## 目录层（投稿者两层 + 维护者一层）

| 目录 | 中文名 | 收录内容 | 投稿者如何判断 |
| --- | --- | --- | --- |
| `photos/modern/` | 当代照片 | 自拍、家人朋友的杖、街头随拍、旅途偶遇 | 照片是当代拍的，就放这里 |
| `photos/historical/` | 公有领域历史影像 | 老照片、画作扫描、古籍插图 | 照片是过去时代的，且确认已入公有领域（附出处） |
| `photos/illustration/` | 场景图鉴插画 | AI 生成示意插画（`source=ai_generated`） | **不对外开放投稿**，仅维护者入库种子/站点配图 |

## 可选标签（复用网站场景图鉴体系）

- **时代（era）**：远古 / 农业 / 工业 / 现代（对应《手杖的历史》四阶段）
- **场景（scene）**：防护 / 探测 / 休息 / 身份

## 历史图收录规则（维护者搜集入库用）

**公有领域判断（快速规则）**

| 法域 | 判断规则 | 实用速算（2026 年） |
| --- | --- | --- |
| 中国《著作权法》 | 法人作品首次发表后 50 年 | 1976 年前发表的作品基本安全 |
| 美国（CTEA） | 1978 年前发表的作品 = 发表后 95 年 | 1931 年前发表的作品已入公有领域 |
| 馆藏图库声明 | 以馆方标注的许可为准 | 优先信任 Wikimedia Commons、LOC 等的明确标注 |

**收录三要件（缺一不入库）**

1. 公有领域确认（符合上表任一规则，或馆方明确标注公有/免版权）；
2. 出处可溯：来源机构 + 作品名/编号 + URL（写入 `source` 列）；
3. 元数据完整：`license=PD`、`source=url`、`alt_text` 必填。

**来源渠道（建议优先顺序）**

- Wikimedia Commons（带明确许可标注，最省心）；
- Library of Congress、NYPL Digital Collections、British Library、Internet Archive；
- 国家图书馆 / 各地博物馆公开数字馆藏（须确认授权口径）；
- 二手博客/图床不用——出处无法核验的不入库。
