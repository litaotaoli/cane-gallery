投稿一张照片

三步即可：选来源、写标题、提交。其余信息都有默认值，不会操作代码也没关系。

  1. 1 填写信息选「我拍的 / 历史图」，起个标题即可
  2. 2 预览照片本地选一张，只在本页预览
  3. 3 提交跳到 GitHub 后把照片拖进附件框，点提交
公有领域声明

你声明这张历史影像属于公有领域（PD），维护者会做基本核实；除标题外无需填写其他信息即可投稿。

点击选择一张 jpg / png 照片

返回画廊

提交后会打开 GitHub 的新 Issue 页面，正文已自动填好；你只需把照片拖进附件框，点「Submit new issue」。维护者审核后会把照片收进画廊。
